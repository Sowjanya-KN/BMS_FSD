# 🏨 BookMyStay

A hotel booking web application built using **React.js**. Users can browse hotels, view available options, and manage their bookings through a simple and responsive interface.

## 🚀 Features

- User Login
- Browse and search hotels
- View hotel details
- Book hotels
- Responsive user interface

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript
- **Routing:** React Router DOM
- **UI:** Material UI, CSS
- **API:** Axios
- **Data:** JSON Server (`db.json`)
